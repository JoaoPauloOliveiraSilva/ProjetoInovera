# Innovera — frontend (React + TypeScript + Vite)

Protótipo com dados de exemplo (ainda sem ligação à API).

- `npm install` — instala as dependências (só da primeira vez)
- `npm run dev` — abre em http://localhost:5173
- `npm run build` — verifica os tipos e gera a versão de produção em `dist/`

Ecrãs: landing "Plataforma de Gestão da Certificação" (só Inovação ativa) → site de Inovação com o layout do site atual
da intranet (homepage, ideias em discussão, todas as ideias, detalhe com likes e comentários, nova ideia em 4 passos,
avaliação de ideias).
